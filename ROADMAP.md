# Roadmap

The ordered overview of what is planned for Læsehjælper. Every open issue appears here exactly once. Details, acceptance criteria and discussion live in the linked GitHub issues.

| Section | Meaning | Label |
|---|---|---|
| **Now** | Being worked on, or next in line | `roadmap` |
| **Next** | Planned after that | `roadmap` |
| **Later** | Wanted, not scheduled yet | – |
| **Ideas** | Needs a decision by the maintainer before it is planned | – |

Within each section, the order is the planned order. "After #…" names a story that has to be merged first. The order of the sub-issues in each epic matches this file. How to keep it up to date: see the end of this file and [CONTRIBUTING.md](CONTRIBUTING.md).

Last reviewed: 14 November 2026.

## Keeping this file up to date

- A pull request that closes an issue removes its line here.
- A new issue gets a line in Later or Ideas. Only the maintainer moves an issue into Now or Next, and adds the `roadmap` label with it.
- When the order changes, change it here and in the epic's sub-issue list.
